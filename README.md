# Разлом Времени

2D survival-adventure игра по мотивам романа "Разлом времени".

## Описание

Мир изменился навсегда. В небе появились фиолетовые трещины — разломы времени. Люди исчезают, города пустеют, а время идёт по кругу. Бывший сапёр Сергей должен преодолеть 2000 км через выжженную землю, чтобы добраться до эпицентра и спасти то, что осталось от человечества.

## Технологии

- **Движок**: Godot 4.x
- **Язык**: GDScript
- **Жанр**: 2D Survival + Narrative Adventure

## Запуск

1. Установите Godot 4.x
2. Откройте проект: `project.godot`
3. Нажмите F5 для запуска
