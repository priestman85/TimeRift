# Промпты для генерации 3D моделей через Gemini

## Персонажи

### Сергей (главный герой)
```
Create a 3D low-poly character model of a 26-year-old Russian man named Sergey.
- Brown short hair, slight stubble
- Military jacket (olive drab), cargo pants, combat boots
- Athletic build, slight limp (injured leg)
- Style: realistic with slight stylization
- Format: FBX or OBJ with textures
- Polycount: 5000-10000 triangles
```

## Как использовать в Gemini

1. Откройте gemini.google.com
2. Вставьте промпт целиком
3. Добавьте: "for use in Unity game engine"
4. Скачайте результат
5. Импортируйте в Unity (Assets → Import New Asset)
