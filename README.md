# Разлом Времени (TimeRift)

3D Third-Person Shooter по мотивам романа "Разлом времени".

## Описание

Мир изменился навсегда. В небе появились фиолетовые трещины — разломы времени. Люди исчезают, города пустеют, а время идёт по кругу. Бывший сапёр Сергей должен преодолеть 2000 км через выжженную землю, чтобы добраться до эпицентра и спасти то, что осталось от человечества.

## Технологии

- **Движок**: Unity 6 (6000.0.83f1)
- **Язык**: C#
- **Жанр**: 3D Third-Person Shooter + Survival

## Запуск

1. Откройте Unity Hub
2. Войдите в аккаунт Unity
3. File → Open Project → выберите папку `H:\Мой диск\Games\TimeRift`
4. Нажмите Play

## Скрипты

| Скрипт | Описание |
|--------|----------|
| `PlayerController.cs` | Движение персонажа, прыжки |
| `PlayerHealth.cs` | Здоровье, голод, жажда |
| `ThirdPersonCamera.cs` | Камера от третьего лица |
| `WeaponSystem.cs` | Стрельба, перезарядка, отдача |
| `EnemyAI.cs` | ИИ врагов (патруль, погоня, атака) |
| `EnemyHealth.cs` | Здоровье врагов |
| `TimeAnomaly.cs` | Временные аномалии |
